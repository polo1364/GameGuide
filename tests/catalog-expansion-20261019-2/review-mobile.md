# 台灣手機遊戲新增研究第二輪（2026-10-19）

建議新增 **13 款**；全數有台灣雙商店商品證據，3 款有本輪台灣免費榜名次，2 款另有官方 Windows 客戶端。新基準目錄為 1,002 款，3,861 個 name／alias／seriesAliases 正規化比對以及 Apple／Google 商品 ID 比對均無重複。只產出研究檔，沒有修改主目錄或待確認的舊 7 筆。

## 方法

台灣 Apple 官方 API 以 country=tw 逐款實讀，保留商品、供應商、iOS 版本、累積評分數與分數。Google Play 以 gl=TW／hl=zh_TW 逐款實讀，13 款均 HTTP 200，結構化資料列 Android、TWD、InStock 並顯示安裝入口。來源逐項列於下方；商店供應證據不等於實機登入測試。

累積評分量是當地參與度指標，不是即時活躍人數或近期討論量，也不代表推薦品質；例如旅遊大亨有評分量但平均分數較低，兩者一併保留。榜單僅為這次讀取的快照。[Apple 台灣 iPhone 免費遊戲榜](https://apps.apple.com/tw/iphone/charts/6014?chart=top-free)

編輯優先級 3：本輪上榜或台灣累積評分至少 25,000；其餘已核實候選為 2。此門檻是目錄編輯決策，不是官方綜合熱門排行。原生 PC 需額外官方證據，Google Play Games 電腦管道另註。
